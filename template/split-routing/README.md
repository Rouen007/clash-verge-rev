# 主订阅 / 从属订阅分流模板

这组模板描述 Clash Verge Rev 的通用分流结构：

```text
当前激活 profile（主订阅）
  ├─ 未匹配网站 → 原有主订阅代理组
  └─ 匹配网站 → SplitRoute 代理组 → 从属 profile provider
```

推荐直接使用代理页的「分流设计」面板。它会把配置写入当前 profile 的增强文件，并在订阅更新后继续保留。手工配置时，将三个文件中的内容合并到当前 profile 对应的增强文件，不要重复创建顶层 YAML key。

## 操作流程

1. 在「配置」页导入一个或多个从属订阅，但不要切换当前主订阅。
2. 打开「代理」→「分流设计」→「添加从属分流」。
3. 选择从属 profile，输入域名列表，例如 `tradingview.com`、`data.tradingview.com`。
4. 保存并等待核心重新加载。
5. 在「代理」页选择对应的 `SplitRoute | <名称>` 组，可在自动测速和从属节点之间切换。

域名只接受主机名，不要写订阅 URL、用户名、密码或完整代理节点。生成的 provider 使用 `./profiles/<profile-file>.yaml` 本地路径，避免把订阅凭据写入增强脚本。

## 回滚

在面板中删除对应的分流并保存即可。面板只清理自身生成的 `SplitRoute |` provider、代理组和规则，不会删除主订阅的原有配置；保存失败时会尝试恢复修改前的增强文件。

## 限制

- 当前面板使用 `DOMAIN-SUFFIX`，适合按网站域名分流；进程、IP、端口等高级规则仍使用原有规则编辑器。
- Clash 规则按连接域名匹配，不是按浏览器标签页匹配。
- provider 文件必须是 Clash/Mihomo 可读取的本地代理配置；订阅更新仍由 Clash Verge Rev 管理。
